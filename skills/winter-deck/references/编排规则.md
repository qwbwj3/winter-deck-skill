# 编排规则 v1：动效由"内容的形状"决定，不按文案类型穷举

## 1. 一条硬规则（步骤契约）
**每按一下，变化必须同时落在文字和画面上。**
一页有多个步骤时，画面不跟着变的元素（比如一张固定的配图）就不该出现在这一页。校验器检查：步骤数 > 1 且配图只有 1 张、又没有区域聚焦 → 报错，要求补图或改成纯文字版式。

## 2. 编排由"形状"决定，只有 6 种
形状 = 这一页有几段文字、几张图、图上有没有要指认的区域、是不是数据。Agent 不判断"这是什么类型的文案"，只把内容按形状填进去，引擎按下表自动选编排。

| 形状 | 编排 | 每一步发生什么 |
|---|---|---|
| N 段文字 + N 张图 | 同步轮播 | 当前段亮起，对应的图从后面飞到最前，上一张退场 |
| 1 段文字 + N 张图 | 图组逐张聚焦 | 每按一下，下一张从队伍里飞到最前并放大，说明文字跟着换 |
| N 段文字 + 1 张图（图上有 N 个要指认的区域） | 区域聚焦 | 镜头推到第 k 个区域，区域外压暗 |
| N 段文字 + 0 张图 | 纯文字逐段 | 当前段亮起；版式改为宽栏，不放装饰图 |
| 1 段文字 + 1 张图 | 单步 | 没有步骤，图文一次到位 |
| 结构化数据 | 3D 数据组件 | 按组件自己的三步动作 |

这 6 种覆盖的是"文字数 × 图片数 × 有无区域"的组合，数量有限；同一种形状，不管讲的是生产、营销还是财务，编排都一样。所以**不需要穷举文案类型**。

## 3. Agent 的工作只剩两件
1. 把内容拆成"段"和"图"，给每张图标角色（证据 / 氛围 / 示意）。
2. 有区域要指认时，给出区域坐标。

编排、镜头、时长、退场方式全部由引擎决定，Agent 不写动效。

## 4. 已实现（样稿 examples/mix-review.json）
- 同步轮播：第 2 页（3 段 × 3 图）
- 图组逐张聚焦：第 5 页（1 段 × 4 图）
- 区域聚焦：第 4 页（证据截图，1 个区域）
- 单步：第 1、6 页
